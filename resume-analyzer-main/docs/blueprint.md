# **App Name**: Career Compass

## Core Features:

- AI Resume Analysis: Leverage the Gemini API to analyze user-uploaded resumes, identifying strengths, weaknesses, and areas for improvement. This tool provides personalized feedback to enhance resume effectiveness.
- Interactive Dashboard: Display resume analysis results in an intuitive dashboard with clear visualizations (charts) and actionable recommendations.
- Mock Interview Simulation: Allow users to select a specific field (e.g., cybersecurity, full-stack development) for mock interviews. The system will then ask related questions, and based on the user's performance, provide a dashboard with results, areas for improvement, and suggestions. This tool uses AI to customize the interview experience and feedback.

## Style Guidelines:

- Primary color: Deep Teal (#008080) to convey professionalism and trust.
- Secondary color: Light Gray (#F0F0F0) for clean backgrounds and content separation.
- Accent: Coral (#FF7F50) to highlight key actions and insights.
- Clean, sans-serif fonts for optimal readability on all devices.
- Simple, professional icons to represent different sections of the dashboard and types of feedback.
- A clean, structured layout with clear visual hierarchy to guide users through the resume analysis and interview preparation process.
- Subtle transitions and animations to provide feedback and guide the user.
